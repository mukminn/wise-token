# wise-token

Next.js dApp for interacting with the rewards smart contract (ABI-driven UI).

## Getting Started

```bash
npm install
npm run dev
```

Open:

- `http://localhost:3000/contract`

Optional query params:

- `?contract=0x...&taskType=...&achievementType=...&referrer=0x...&amount=...&castHash=0x...`
